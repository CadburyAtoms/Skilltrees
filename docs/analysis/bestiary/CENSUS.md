# Bestiary census — measured ground truth for the 52 adversary blocks

Generated by `node scripts/bestiary-census.js --write` — **do not edit by hand.** Read straight from `data/adversaries.json` @ `af74933c32ab` and the 21 authored overlays @ `f704cbaf139d`; regenerate after either changes (`tests/bestiary-census.test.js` fails while this file is stale). The standard these numbers are read against is `.claude/skills/bestiary-forge/STANDARD.md`; the scope licence is R-101 (a): a yardstick, not a finding about adversary design.

**Per hit, not per turn.** Every damage figure is the expected value of one landed hit (dice average plus flat modifier). Actions per turn, hit rates against real defenses and the graze floor are table facts the bestiary yardstick bench fights measure, on copies of the actual PCs.
